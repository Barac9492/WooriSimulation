# 고등부 목회 계획 시뮬레이터

한 해의 설교 시리즈, 수련회, 행사 계획을 짜고 그 계획대로 공동체가 어떻게 흘러가는지 지켜보는 도구다. 학생 한 명 한 명을 작은 행위자로 두고, 친구 관계와 사역에 따라 출석과 신앙 관심도가 어떻게 달라지는지 본다. 분당우리교회 고등부 한 부(약 150명)를 기준으로 맞춰 두었다.

출석은 두 층으로 움직인다. 천천히 쌓이는 '헌신'과, 그 위에 잠깐 얹히는 '일시 변동'이다. 그래서 시험기간엔 출석이 일시적으로 떨어졌다 끝나면 회복되고, 수련회엔 일시적으로 솟구친 뒤 조금 높아진 자리에 정착한다. 화면의 "변화 속도"를 낮추면 전체가 더 느리고 끈기 있게(실제에 가깝게) 변한다.

## 1. 바로 실행하기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것도, 켜둘 서버도 없다.

## 2. 전제

화면 맨 위 "전제" 박스가 이 도구의 가정을 밝힌다. 출석과 신앙은 친구 관계와 사역으로 천천히 움직이며, 효과 수치는 가정값이지 검증된 사실이 아니다. 그래서 여기서 보는 것은 현실 예측이 아니라 "이 전제대로라면 이렇게 흘러간다"는 한 가지 **시나리오**다.

## 3. 두 가지 모드

상단 토글로 고른다.

- **관찰 (기본·메인)** : 첫 화면이다. 위에서 본 교실이 한 주씩 흐른다. 점 하나가 학생 한 명이다. 초록은 활발, 노랑은 느슨, 빨강은 이탈 위기, 머리 위 금색 점은 신앙 관심도가 높다는 뜻이다. 계획을 짜고 공동체가 어떻게 움직이는지 지켜보는 것이 이 도구의 중심이다.
- **시나리오 (보조)** : "시나리오 실행"을 누르면, 같은 계획대로 한 해(또는 2~3·5년)를 끝까지 돌린 평균 결과가 바로 나온다. 특별 계획 없이 평소 운영만 했을 때와 나란히 견줘, 이 계획이 무엇을 바꾸는지 보여준다.

## 4. 계획 짜는 법

화면을 위에서 아래로 채워 나간다.

1. **운영 설정** : 소그룹·멘토링 비중, 교사 수, 연간 신입생 등 평소 사역의 밀도.
2. **연간 계획** : 핵심이다. 종류를 고르고 시작 주차를 정해 더한다.
   - **설교 시리즈** : 초점(양육형·전도형·회복형)과 기간(주)을 정한다. 효과는 즉시 나오지 않고 시리즈가 이어지는 동안 서서히 쌓이며, 끝난 뒤에도 한동안 이어진다. 양육형은 코어·소그룹원에게, 전도형은 신앙이 옅거나 비신앙 가정 학생에게, 회복형은 출석이 흔들리는 학생에게 닿는다.
   - **수련회** : 기간(1·2·3박), 시점, 참가율, 강도를 정한다. 참가한 학생에게만 큰 힘이 되고 몇 주 동안 지속된다. 길고 강할수록 효과가 크지만, 참가하지 못한 학생과의 격차도 함께 벌어진다.
   - **전도·소그룹 집중·봉사·시험기간** : 그 주에 작용하는 행사와 이탈 요인.
3. **우리 교회 설정** : 학년 구성, 신앙 배경, 코어·외톨이 비율을 실제 고등부에 맞춘 뒤 "이 분포로 새로 생성"을 누른다.
4. **시나리오 실행** : 상단 토글에서 "시나리오"로 바꾼 뒤 기간을 고르고 실행한다.
5. **약점·처방 분석** : 시나리오 모드의 버튼이다. 이 계획의 약점(이탈 증가, 신앙 하락, 인원 감소 등)을 짚고, 개입안(회복형 설교, 멘토링 강화, 수련회 강화 등)을 각각 실제로 돌려 효과를 검증한 뒤 좋은 순으로 추천한다. 마음에 드는 처방은 "적용"을 누르면 위 계획·설정에 바로 반영된다.
6. **시나리오 비교 (A/B)** : 두 안을 같은 기간 견준다. 예를 들어 수련회를 1년차에 둘 때와 2년차에 둘 때, 또는 설교를 양육형으로 갈 때와 전도형으로 갈 때.

## 5. Claude Code로 키우기

이 폴더가 Claude Code 프로젝트다. 코드를 직접 쓸 필요 없이, 하고 싶은 일을 한국어로 말하면 된다.

방법:
1. 터미널에서 이 폴더로 이동한 뒤 `claude`를 실행한다. (또는 Claude Code 앱에서 이 폴더를 연다.)
2. 원하는 것을 문장으로 요청한다.

요청 예시:
- "시나리오 결과를 목회 보고용 한 장짜리 PDF로 뽑는 버튼을 만들어줘."
- "지금 짠 연간 계획과 설정을 저장하고 다시 불러오는 기능을 넣어줘."
- "실제 출석 데이터를 CSV로 넣을 테니, 시작 분포와 효과 수치를 그 데이터에 맞게 보정해줘."
- "시나리오 결과에 8회 평균의 편차(신뢰구간)를 같이 보여줘."

`CLAUDE.md` 파일에 이 프로젝트의 모형 규칙과 전제가 정리되어 있어서, Claude Code가 맥락을 이해하고 일관되게 고친다. 그 파일은 지우지 말 것.

## 6. Claude Code 설치 (이미 쓰고 있다면 건너뛰어도 된다)

설치 방법은 두 가지다. 의존성 없는 네이티브 설치 프로그램(권장)과, Node.js 18 이상이 필요한 npm 설치다. 현행 공식 안내는 아래에서 확인한다.

- 공식 문서: https://docs.claude.com/en/docs/claude-code/overview

사용하려면 Claude Pro/Max 구독 또는 Anthropic API 키가 필요하다.

## 한 가지 전제

화면의 효과 수치(수련회가 출석을 얼마나 올리는지, 설교 시리즈가 신앙을 얼마나 끌어올리는지 등)는 그럴듯하게 넣은 가정값이지 검증된 사실이 아니다. 실제 결론을 내리는 도구가 아니라, 계획의 방향과 크기를 가늠하고 가설을 세워 다듬는 도구로 보는 것이 맞다.
