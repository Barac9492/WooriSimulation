# 중고등부 목회 수첩

목사·교역자가 두 가지를 보는 도구다. **지금**(우리 아이들 누가 흔들리나, 누구를 먼저 만날까)은 실제 데이터(출석부·명단·교사 관찰)로 진단하고, **앞날**(올해 이렇게 계획하면 어떻게 되나)은 행위자 기반 모형으로 가늠한다. 학생 한 명 한 명을 작은 행위자로 두고 친구 관계와 사역에 따라 출석·신앙이 1주 단위로 천천히 달라지는 모형을 화면 없이 여러 번 돌려 그 평균을 보여 준다. 분당우리교회 중고등부 한 부(약 120~150명) 기준이다.

> **한계** : 앞날 수치는 검증된 사실이 아니라 그럴듯하게 넣어 본 가정값이다. 현실 예측이 아니라 "이 전제대로라면 이렇게 흘러간다"는 방향 참고용이다. 화면에도 [모형 전망] 표시가 붙는다. 모형 규칙과 근거는 `CLAUDE.md`·`METHODOLOGY.md`에 있다.

## 1. 바로 실행하기

`index.html`을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것도, 켜둘 서버도, 인터넷도 필요 없다.

화면은 큰 탭 셋이다.

- **이번 주** (기본) : 지금 상태 한 문장(신호등) + 이번 주 만날 아이 + 이번 주 한 가지 + 한 장 보고서. 실측 진단 화면이라 차트가 없다.
- **올해 계획** : 설교 결과 프로그램을 고르면 "졸업하는 아이 열 명 중 몇이 믿음을 지니고 나가나"가 사람 그림으로 나온다(아무것도 안 할 때와 비교, 모형 전망).
- **자세히** : 교역자·분석용. 전염 지도·믿음 지수·상황도 같은 그래프와, 시간을 흘려 보는 모의 실험(다음 주 ▶)이 여기 있다.

## 2. 우리 부 명단 넣기 (실측 진단의 시작)

첫 화면의 **세 걸음**을 따라가면 된다.

1. **명단 양식 받기** : 출석부·행정 기록(이름·학년·출석4주·소그룹·멘토·봉사역할)만으로 시작할 수 있다. 모르는 칸은 비워 둔다.
2. **채운 명단 올리기** : 올리면 바로 우리 아이들 이름으로 진단이 나온다. 출석 칸만 바꿔 다시 올리면 진단이 새로워진다. **구글 시트 링크**(파일 → 공유 → 웹에 게시 → CSV)를 붙여 넣으면 다음 방문 때 자동으로 새 명단을 받아 온다.
3. **더 정확히** : 교사 관찰지(자기 반 6명, 본 행동만), 학부모 설문지(신앙 대화·가정예배 두 가지 사실), 학생 설문지(연 1회, 내면화 6문항)를 인쇄해 모으고 명단 칸에 옮긴다.

모든 칸은 **관찰하거나 기록에서 옮길 수 있는 것**만 받는다. 속마음을 짐작해 적는 칸은 없다(원칙과 문항 근거는 `SURVEY.md`). 화면의 수치마다 출처 배지(출석부·행정 / 교사 관찰 / 설문 / 모형 전망 / 추정)가 붙어 무엇이 실측이고 무엇이 짐작인지 구분된다.

옛 양식과 `collection-template.csv`(이름·학년·신앙배경·코어·외톨이·출석상태 + 풍부 칸) 형식도 그대로 읽힌다. `sample-data.csv`(112명)를 올려 둘러봐도 된다. **친구이름/친한친구** 칸에 주로 함께 다니는 아이 이름을 적으면, 전염 진단과 "먼저 만날 아이" 순서가 추정이 아니라 실제 관계망으로 계산된다.

업로드한 명단은 브라우저 안(localStorage)에만 저장되고 어디로도 전송되지 않는다. 이름 명단과 민감한 속(내면화) 정보는 역할(담임·교사·부모)에 따라 가려진다. 점수로 아이를 평가·서열화하지 않는다(목양이지 사찰이 아니다, `STEERING.md`).

## 3. 개발자 참고

- 빌드 없음, 외부 라이브러리 없음. `index.html` 한 파일이 전부다.
- 스모크 테스트 : `cd tests && npm install && npx playwright test` (실제 브라우저로 핵심 흐름을 돌린다). CI는 `.github/workflows/test.yml`.
- 문서 : `CLAUDE.md`(구조·모형 규칙) · `SURVEY.md`(관찰 원칙·설문) · `COLLECTION.md`(수집 양식) · `DIAGNOSIS.md`("약해졌다"의 정의) · `STEERING.md`(헌장) · `METHODOLOGY.md`(학술 근거).
