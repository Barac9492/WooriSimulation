🔗 구글 시트 명단 링크:
구글 시트 → 파일 → 공유 → 웹에 게시 → 쉼표로 구분된 값(.csv)으로 게시한 링크를 붙여라. 일반 시트 링크(보기 권한 공개)도 자동 변환을 시도한다. 머리글은 업로드 CSV와 같다(이름,학년,신앙배경,코어,외톨이,출석상태). 명단은 이 브라우저에서만 쓰인다.
전제 — 이 대시보드는 시뮬레이터 결과를 시각화한다. 수치는 검증되지 않은 가정값이다. (자세히 ▾)
출석·신앙이 친구 관계와 사역(소그룹·멘토·설교·수련회)으로 천천히 움직인다는 전제 위에서 실제 행위자 기반 모형(학생 한 명이 행위자, 1주 단위)을 돌린 시나리오다. 분당우리교회 중고등부 한 부(약 120명) 기준 가정값. "예측"이 아니라 "이 전제대로라면 이렇게 흘러간다"는 방향 참고용이다. 근거 문헌은 METHODOLOGY.md.
