# 할 일: 현실형 2층 모형 + 처방 엔진 + 분당우리 보정

## 방향 (사용자 확정)
- 한 부(~150명) 기준으로 정확히 보정. 1·2부 분리는 다음 단계.
- 더 느리고 실제 같은 변화: 출석을 '느린 헌신(commit)' + '일시 변동'으로 나눈 2층 모형 + 변화 속도 슬라이더.
- 시험기간엔 일시 하락 후 회복, 수련회엔 일시 급등 후 정착.
- 문제를 막는 처방을 제안하되 각 처방을 실제로 돌려 개선폭으로 검증·순위.

## 분당우리 고등부(한 부) 보정값
- 전체 ~150명, 1>2>3학년(가중 40/34/26).
- 교사 ~8~9명/학년 → 한 부 ~25명. 교사 슬라이더 max 40, 기본 25.
- 연간 신입(1학년 유입) 기본 ~50.

## 모형(2층)
- 학생: `commit`(느린 헌신 0~1), `eng`(표시 출석=commit+일시변동), `examPress`(시험 일시압박), `retreatGlow`(수련회 여운), `sermonAcc`.
- `commit += speed * 힘`(속도 슬라이더가 변화 폭을 줄임). 친구 효과는 commit 기준.
- 시험: 기간 동안 `examPress`↑(상한 0.30), 끝나면 빠르게 회복 → 일시 하락.
- 수련회: 참가자만 `retreatGlow` 급등(일시) + 작은 영속 commit 상승.
- 표시 `eng = clamp(commit + 0.20*glow - examPress)`. 지표·이탈은 표시 eng 기준(시험 단독으론 이탈 안 됨).

## 처방 엔진
- 예측 결과에서 약점 진단(이탈·위기·신앙추세·인원감소).
- 후보 개입(회복/양육 설교, 멘토링↑, 소그룹↑, 교사↑, 수련회 강화)을 각각 같은 기간 돌려 개선폭 점수로 순위.
- 양수 개선 상위 3개를 효과 델타와 함께 제시, [적용] 누르면 실제 계획/슬라이더에 반영.

## 리뷰

완료. `index.html` 한 파일, 외부 의존성 없음. 콘솔 오류 0.

**한 일**
- **2층 출석 모형**: 느린 `commit` + 일시 `examPress`/`retreatGlow`. 표시 출석 = commit + 수련회 여운 − 시험 압박. 친구 효과·이탈은 안정적인 신호 기준이라 시험 단독으론 이탈하지 않는다.
- **변화 속도 슬라이더**(기본 40%): 낮을수록 모든 변화가 느리고 끈기 있게 — 실제 공동체에 가깝다.
- **시험기간**을 기간 이벤트로(기본 3주): 동안 떨어졌다 끝나면 회복. **수련회**는 참가자만 일시 급등 + 작은 영속 상승.
- **처방 엔진**: 예측에서 약점 진단 → 후보 개입(설교·멘토링·소그룹·교사·수련회)을 각각 같은 기간 돌려 개선 점수로 순위 → 상위 3개를 효과 델타와 함께 추천 → "적용"으로 실제 계획·슬라이더에 반영.
- **분당우리 한 부 보정**: 150명, 1>2>3학년(40/34/26), 교사 25, 신입 50. 관찰 좌석 180석.

**검증(헤드리스 브라우저)**
- 시험기간(8~10주) 활발 131→60으로 일시 하락, 11주 109로 반등, 12주 133 회복. 전체 150 불변(이탈 0) → 일시성 확인.
- 건강한 기본 계획: "큰 문제 없음" 진단 + 멘토링↑(활발+13/신앙+4%p) 등 검증 순 추천. 적용 시 슬라이더 반영.
- 사역을 걷어낸 스트레스 계획: 이탈 과다·신앙 하락·인원 감소 진단 정확, 멘토링↑(이탈−11/신앙+18%p) 등 회복 처방 추천.

**남은 좋은 작업**
- 1·2부 분리, 실제 출석 CSV 보정, 시험 하락폭 미세조정. (리포트/PDF·저장/불러오기·신뢰구간은 완료)
