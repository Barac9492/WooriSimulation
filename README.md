# 고등부 목회 계획 시뮬레이터

한 해의 설교 시리즈, 수련회, 행사 계획을 짜고 그 계획대로 공동체가 어떻게 흘러가는지 지켜보는 도구다. 학생 한 명 한 명을 작은 행위자로 두고, 친구 관계와 사역에 따라 출석과 신앙 관심도가 어떻게 달라지는지 본다. 분당우리교회 고등부 한 부(약 150명)를 기준으로 맞춰 두었다.

출석은 두 층으로 움직인다. 천천히 쌓이는 '헌신'과, 그 위에 잠깐 얹히는 '일시 변동'이다. 그래서 시험기간엔 출석이 일시적으로 떨어졌다 끝나면 회복되고, 수련회엔 일시적으로 솟구친 뒤 조금 높아진 자리에 정착한다. 화면의 "변화 속도"를 낮추면 전체가 더 느리고 끈기 있게(실제에 가깝게) 변한다.

## 1. 바로 실행하기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것도, 켜둘 서버도 없다.

## 2. 전제

화면 맨 위 "전제" 박스가 이 도구의 가정을 밝힌다. 출석과 신앙은 친구 관계와 사역으로 천천히 움직이며, 효과 수치는 가정값이지 검증된 사실이 아니다. 그래서 여기서 보는 것은 현실 예측이 아니라 "이 전제대로라면 이렇게 흘러간다"는 한 가지 **시나리오**다.

## 3. 세 가지 탭

상단 토글로 고른다. 첫 화면은 복잡하지 않게 **관찰**만 보인다.

- **관찰 (기본·메인)** : 첫 화면이다. 위에서 본 교실이 한 주씩 흐른다. 점 하나가 학생 한 명이다. 초록은 활발, 노랑은 느슨, 빨강은 이탈 위기, 머리 위 금색 점은 신앙 관심도가 높다는 뜻이다. **"다음 주 ▶"로 한 주씩 직접 넘기며** 그 주의 입력(진행 중인 설교 시리즈·수련회·시험기간·행사)을 칩으로 검토하고, 바로 아래 "이번 주 효과(지난주 대비)"로 그 입력이 출석·신앙을 어떻게 움직였는지 확인한다. 그냥 두고 싶으면 **자동재생**(속도 1·2·4배)으로 흘려보낸다. 지표 카드·위기군 구성·돌봄 명단·추이까지 한 화면에서 본다.
- **시나리오** : "시나리오 실행"을 누르면, 같은 계획대로 한 해(또는 2~3·5년)를 끝까지 돌린 평균 결과가 바로 나온다. 평소 운영만 했을 때와 나란히 견주고, **취약 분석**(어떤 학생이 빨리 빠지는지)과 변동 폭도 함께 본다. 약점·처방 분석, 공유 요약, A/B 비교가 이 탭에 있다.
- **설정** : 우리 부와 계획을 맞추는 곳이다. 맨 위 **주간 계획표**에 각 주마다 무엇을 할지(설교·수련회·시험·담임 말씀·전교인 행사)가 죽 펼쳐진다. 한 주를 눌러 그 주에 넣고, 다 짠 뒤 **"이 계획대로 돌려보기"**로 관찰에서 실행한다. 그 아래 운영 설정·가정·교회(다락방·전체 교회)·연간 계획·교회 설정·계획 저장이 있다.

시뮬레이션은 로드되자마자 멋대로 돌지 않는다. **계획을 먼저 짠 뒤** 관찰에서 "다음 주 ▶"로 한 주씩 넘기거나 "자동재생"으로 흘려보낸다.

이 도구는 고등부를 진공 속에 두지 않는다. **담임목사의 어른 말씀, 전교인 수련회·부흥회·절기**가 교회 전체 분위기를 끌어올리고 → **부모 다락방**이 살아나고 → 학생의 가정신앙이 오르고 → 고등부가 따라 오른다. 청소년 사역만으로는 닿지 못하는 천장이 여기서 정해진다. 관찰 화면 위쪽 "교회 생태계" 막대로 교회 분위기·부모 다락방 활성도를 실시간으로 본다.

관찰 화면의 지표 카드 아래에는 "위기군이 지금 누구인가"가 실시간으로 뜬다. 위기 학생이 몇 학년에, 외톨이·비신앙 가정·비코어에 얼마나 몰려 있는지 바로 짚어, 실제 우리 반의 그 아이들을 떠올리게 한다. 또한 교실의 **점(학생) 하나를 클릭하면** 그 아이의 학년·신앙 배경·출석·신앙·친구 수와 "지금 이 아이에게 필요한 것"이 한 줄로 뜬다. 숫자가 아니라 한 영혼으로 내려가 보는 창이다.

그 아래 **이번 주 돌봄 명단**을 펼치면, 출석이 무너진 학생들이 약한 순서로 모인다. 각자의 처지(학년·외톨이·소그룹 밖 등)와 한 줄 처방이 붙어, 주일 아침 심방·연락 명단으로 바로 쓸 수 있다.

## 4. 계획 짜는 법

먼저 **설정** 탭으로 가서 1~3을 맞춘 뒤, **시나리오** 탭에서 4~7을 본다.

1. **운영 설정**(설정 탭) : 소그룹·멘토링 비중, 교사 수, 연간 신입생, 변화 속도 등 평소 사역의 밀도.
2. **연간 계획**(설정 탭) : 핵심이다. 종류를 고르고 시작 주차를 정해 더한다.
   - **설교 시리즈** : 초점(양육형·전도형·회복형)과 기간(주)을 정한다. 효과는 즉시 나오지 않고 시리즈가 이어지는 동안 서서히 쌓이며, 끝난 뒤에도 한동안 이어진다. 양육형은 코어·소그룹원에게, 전도형은 신앙이 옅거나 비신앙 가정 학생에게, 회복형은 출석이 흔들리는 학생에게 닿는다.
   - **수련회** : 기간(1·2·3박), 시점, 참가율, 강도를 정한다. 참가한 학생에게만 큰 힘이 되고 몇 주 동안 지속된다. 길고 강할수록 효과가 크지만, 참가하지 못한 학생과의 격차도 함께 벌어진다.
   - **전도·소그룹 집중·봉사·시험기간** : 그 주에 작용하는 행사와 이탈 요인.
3. **가정·교회**(설정 탭) : 부모 다락방 참여율을 정하고, "전체 교회 일정"에 담임 말씀 시리즈·전교인 수련회·부흥회·절기를 더한다. 전체 교회가 살아 있을수록 고등부의 천장이 높아진다.
4. **우리 교회 설정**(설정 탭) : 학년 구성, 신앙 배경, 코어·외톨이 비율을 실제 고등부에 맞춘 뒤 "이 분포로 새로 생성"을 누른다.
5. **시나리오 실행**(시나리오 탭) : 상단 토글에서 "시나리오"로 바꾼 뒤 기간을 고르고 실행한다.
6. **공유 요약** : 시나리오 모드의 버튼이다. 우리 부 설정·연간 계획·전망·취약·1순위 처방을 한 덩어리 텍스트로 뽑아 복사한다. 교사팀 카톡이나 보고 문서에 그대로 붙여 넣어 공유한다.
7. **약점·처방 분석** : 시나리오 모드의 버튼이다. 이 계획의 약점(이탈 증가, 신앙 하락, 인원 감소 등)을 짚고, 개입안(회복형 설교, 멘토링 강화, 수련회 강화 등)을 각각 실제로 돌려 효과를 검증한 뒤 좋은 순으로 추천한다. 마음에 드는 처방은 "적용"을 누르면 위 계획·설정에 바로 반영된다.
8. **시나리오 비교 (A/B)** : 두 안을 같은 기간 견준다. 예를 들어 수련회를 1년차에 둘 때와 2년차에 둘 때, 또는 부모 다락방·전체 교회가 살아 있을 때와 잠잠할 때.
9. **계획 저장·불러오기**(설정 탭) : 지금 짠 운영·연간 계획·교회 설정을 이름 붙여 저장한다. 이 브라우저에 남으니 다음에 다시 열어 이어 가거나 여러 안을 두고 견줄 수 있다.

## 5. Claude Code로 키우기

이 폴더가 Claude Code 프로젝트다. 코드를 직접 쓸 필요 없이, 하고 싶은 일을 한국어로 말하면 된다.

방법:
1. 터미널에서 이 폴더로 이동한 뒤 `claude`를 실행한다. (또는 Claude Code 앱에서 이 폴더를 연다.)
2. 원하는 것을 문장으로 요청한다.

요청 예시:
- "시나리오 결과를 목회 보고용 한 장짜리 PDF로 뽑는 버튼을 만들어줘."
- "지금 짠 연간 계획과 설정을 저장하고 다시 불러오는 기능을 넣어줘."
- "실제 출석 데이터를 CSV로 넣을 테니, 시작 분포와 효과 수치를 그 데이터에 맞게 보정해줘."
- "시나리오 결과에 8회 평균의 편차(신뢰구간)를 같이 보여줘."

`CLAUDE.md` 파일에 이 프로젝트의 모형 규칙과 전제가 정리되어 있어서, Claude Code가 맥락을 이해하고 일관되게 고친다. 그 파일은 지우지 말 것.

## 6. Claude Code 설치 (이미 쓰고 있다면 건너뛰어도 된다)

설치 방법은 두 가지다. 의존성 없는 네이티브 설치 프로그램(권장)과, Node.js 18 이상이 필요한 npm 설치다. 현행 공식 안내는 아래에서 확인한다.

- 공식 문서: https://docs.claude.com/en/docs/claude-code/overview

사용하려면 Claude Pro/Max 구독 또는 Anthropic API 키가 필요하다.

## 한 가지 전제

화면의 효과 수치(수련회가 출석을 얼마나 올리는지, 설교 시리즈가 신앙을 얼마나 끌어올리는지 등)는 그럴듯하게 넣은 가정값이지 검증된 사실이 아니다. 실제 결론을 내리는 도구가 아니라, 계획의 방향과 크기를 가늠하고 가설을 세워 다듬는 도구로 보는 것이 맞다.
