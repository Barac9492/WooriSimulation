# 중고등부 사역 분석 대시보드

목사·교역자가 한 해 사역 계획(설교·수련회·소그룹·멘토)이 우리 부 출석과 신앙을 어떻게 움직이는지 가늠하는 도구다. 학생 한 명 한 명을 작은 행위자로 두고, 친구 관계와 사역에 따라 출석·신앙이 1주 단위로 천천히 달라지는 행위자 기반 모형을 화면 없이 여러 번 돌려, 그 평균 결과를 차트와 표로 보여 준다. 분당우리교회 중고등부 한 부(약 120~150명) 기준이다.

도구의 핵심은 "우리 부 실제 명단에서 출발해, 이 계획이 우리를 들어올리는가"를 보는 것이다. 명단을 올리면 그 학생들이 시뮬레이션 시작 인구가 되고, 계획대로 1년을 흘린 결과(활발·느슨·위기 인원, 평균 신앙, 누적 이탈)를 평소 운영만 했을 때와 나란히 견준다.

> **한계** : 화면의 모든 효과 수치는 검증된 사실이 아니라 그럴듯하게 넣어 본 가정값이다. 현실 예측이 아니라 "이 전제대로라면 이렇게 흘러간다"는 방향 참고용이다. 모형의 규칙과 근거는 `CLAUDE.md`에 정리돼 있다.

## 1. 바로 실행하기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것도, 켜둘 서버도 없다. 처음 열면 샘플 명단(112명)으로 동작한다.

### 우리 부 실제 명단 넣기 (백데이터)

상단 **📁 명단 CSV 업로드**로 우리 부 실제 명단을 넣으면, 그 학생들이 시작점이 되어 모든 카드·차트·취약 분석이 우리 부 데이터에서 출발한 결과로 바뀐다. CSV 머리글은 다음과 같다(엑셀에서 만들어 "CSV로 저장").

```
이름,학년,신앙배경,코어,외톨이,출석상태
홍길동,고1,모태,N,N,활발
김믿음,중2,일반,Y,N,느슨
이소망,중3,비신앙,N,Y,위기
```

- **학년** : 중1·중2·중3·고1·고2·고3
- **신앙배경** : 모태·일반·비신앙
- **코어**(헌신된 핵심)·**외톨이** : Y 또는 N
- **출석상태** : 활발·느슨·위기

양식이 필요하면 상단 **⬇ 샘플 양식**으로 `sample-data.csv`를 내려받아 고쳐 쓰면 된다. 엑셀에서 "CSV UTF-8"로 저장한 파일(따옴표로 감싼 칸 포함)도 읽는다. 올린 명단의 학생 이름은 **교사팀 상세** 탭 맨 아래 "업로드 명단"에서 위기·느슨 학생부터 차례로 확인할 수 있다. 업로드한 명단은 브라우저 안에서만 쓰이고 어디로도 전송되지 않는다. 앞으로의 1년 흐름은 여전히 가정값 시뮬레이션이다(시작만 실제 명단).

## 2. 화면 보는 법

상단바에서 **탭**(담임 요약·교사팀 상세)과 **시나리오**(우리 부 데이터·계획·기본 운영·쇠퇴 부)를 고르고, **📁 명단 CSV 업로드**·**⬇ 샘플 양식**·**🖨 인쇄·PDF** 버튼을 쓴다. 기본은 담임 요약 탭에 우리 부 데이터(샘플 또는 업로드 명단)다.

### 담임 요약 (한눈에)

- **숫자 카드 넷** : 현재 활발·위기군·평균 신앙·누적 이탈. 각 카드 아래 "시작 대비" 증감으로 1년간 어디로 움직였는지 본다.
- **활발·위기·신앙 추이** : 1년(52주) 동안 세 무리와 평균 신앙이 어떻게 흐르는지 한 그래프로.
- **종합 판정** : 신호등 한 줄(양호·보통·살핌·주의)로 지금 상태와 다음 한 수를 짚는다. 계획과 기본 운영의 활발 인원 차이, 졸업 후 신앙을 지킬 비율도 함께 적힌다.
- **계획 vs 기본 운영 비교** : 짠 계획대로 갈 때와 특별 계획 없이 평소 운영만 할 때, 두 선이 벌어진 만큼이 곧 계획의 효과다.

### 교사팀 상세 (자세히)

- **숫자 카드 넷** : 전체 인원·활발(출석 55% 이상)·느슨(30~55%)·위기(30% 미만).
- **출석 구성 추이 / 위기군 구성** : 활발·느슨·위기 인원이 쌓이는 막대, 그리고 지금 위기군이 어떤 유형(외톨이·비신앙 가정·비코어)에 몰렸는지 도넛으로.
- **신앙 평균 추이 / 신앙의 갈래** : 평균 신앙의 흐름과, 말씀·거룩·소속 세 갈래가 따로 어떻게 움직이는지.
- **설교 결별 효과 / 수련회 박수별 효과** : 양육·전도·회복·말씀·거룩·은혜 여섯 설교 결을 같은 기간 돌렸을 때 활발·신앙 변화(결마다 트레이드오프가 있다), 그리고 1박·2박·3박 수련회의 활발 증가폭.
- **계획 vs 기본 운영 상세 비교** : 추이 그래프와 지표 표(전체·활발·느슨·위기·이탈·신앙)로 차이를 숫자까지 본다.
- **취약 분석** : 외톨이 여부·신앙 배경·코어 여부·학년별로 누가 가장 빨리 빠지는지.
- **지렛대 민감도** : 소그룹·멘토·교사·수련회·부모 다락방·변화 속도를 각각 흔들었을 때 1년 뒤 활발 인원이 얼마나 출렁이는지. 위쪽에 있을수록 먼저 손볼 곳이다.
- **업로드 명단** : 올린 명단의 학생을 위기·느슨부터 차례로 보여 준다(이름·학년·배경·코어·외톨이·출석상태). 숫자 뒤의 실제 아이들을 떠올리는 자리다.

## 3. 시나리오 고르기

상단 시나리오 선택으로 같은 화면을 다른 전제로 본다.

- **우리 부 데이터 (CSV)** : 업로드한(또는 샘플) 명단에서 출발한다. 기본값이다.
- **계획 시나리오 / 기본 운영만 / 쇠퇴 부** : 명단 없이 가정 분포로 만든 비교용 시나리오다. 우리 부 데이터가 없을 때 도구의 작동을 살펴보거나, 건강한 부와 쇠퇴하는 부의 궤적을 견주는 데 쓴다.

어느 시나리오든 "계획"과 "기본 운영"을 같은 시작·같은 기간으로 돌려 견준다. 시작 분포(규모·학년·배경·코어·외톨이·활발/위기 비율)와 사역 밀도(소그룹·멘토·교사 수 등)는 모형 안에 가정값으로 박혀 있으며, 손보려면 `CLAUDE.md`의 안내대로 `index.html`의 `SC_DEFS`를 고친다.

## 4. 꼭 기억할 한 가지

효과 수치는 그럴듯하게 넣어 본 값이지 확인된 사실이 아니다. 현실을 맞히는 도구가 아니라, 계획의 방향과 크기를 가늠하고 생각을 다듬는 도구다. 숫자 하나로 단정하지 말고 방향으로 읽으라. 점수로 사람을 평가하거나 서열화하지 않는다. 목양이지 사찰이 아니다.
